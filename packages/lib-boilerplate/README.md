## Usage

### Install

```sh
# npm
npm i lib-boilerplate

# yarn
yarn add lib-boilerplate

# pnpm
pnpm add lib-boilerplate

# bun
bun add lib-boilerplate
```

### API

```js
import echo from 'lib-boilerplate'

echo()
```
